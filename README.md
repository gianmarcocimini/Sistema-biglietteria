# Sistema-biglietteria
Primo progetto Python: sistema semplice per la gestione dei biglietti 

Cosa fa
Il programma chiede all’utente:
* la propria età
* se possiede già un biglietto
In base alle informazioni inserite, il programma comunica se l’utente può entrare e il prezzo del biglietto.

Con questo progetto ho utilizzato:
* input()
* variabili
* if
* elif
* else
* operatori di confronto
* operatori logici

Tecnologie
* Python
